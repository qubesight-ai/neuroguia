# **Guía Social Clara**

Crea un sitio web completo, moderno, accesible y responsive llamado “NeuroGuía”, dirigido a adolescentes y adultos autistas, con TDAH, ansiedad social y otras neurodivergencias.

OBJETIVO DEL SITIO

NeuroGuía será una plataforma educativa e interactiva para ayudar a personas neurodivergentes a comprender normas sociales, situaciones ambiguas, relaciones, límites personales, comunicación y regulación emocional.

El sitio no debe presentar la neurodivergencia como una enfermedad que necesita ser corregida. Tampoco debe enseñar a ocultar rasgos autistas ni obligar a las personas a comportarse como neurotípicas.

Su objetivo será:

Explicar situaciones sociales de manera clara y literal.

Reducir la incertidumbre y la ansiedad.

Ofrecer diferentes formas válidas de responder.

Ayudar a reconocer límites, manipulación, abuso y relaciones poco saludables.

Permitir que cada persona decida si desea seguir una norma social.

Explicar que las normas sociales cambian según la cultura, el contexto y las personas.

Validar la comunicación directa y las necesidades neurodivergentes.

FRASE PRINCIPAL

“Comprender las normas sociales sin dejar de ser tú.”

FRASE SECUNDARIA

“Explicaciones claras, ejemplos reales y herramientas prácticas para navegar situaciones sociales con mayor seguridad.”

PÚBLICO

El contenido debe ser comprensible para adolescentes y adultos. Utiliza lenguaje sencillo, directo, respetuoso y no infantilizado.

Color de apoyo: lavanda #9A86D4.

Texto principal: azul oscuro #24324A.

Advertencias: amarillo cálido suave.

El diseño debe evitar:

Colores neón.

Animaciones rápidas.

Fondos que se muevan.

Parpadeos.

Exceso de elementos decorativos.

Pantallas saturadas de información.

Lenguaje infantil.

Tipografía:

Utiliza Atkinson Hyperlegible, Inter o una tipografía sans serif altamente legible.

El usuario debe poder aumentar el tamaño del texto.

Mantén una separación cómoda entre líneas y párrafos.

No uses bloques extensos de texto sin dividir.

Contraste adecuado.

DETALLE DE UNA SITUACIÓN

Cada situación debe seguir esta estructura:

“¿Qué está pasando?”

“¿Por qué puede ser confuso?”

“Qué podría significar”.

“Otras interpretaciones posibles”.

“Señales que puedes observar”.

“Preguntas directas que puedes hacer”.

“Opciones para responder”.

“Qué podría ocurrir con cada respuesta”.

“Lo que no estás obligado a hacer”.

“Cuándo poner un límite”.

“Cuándo pedir ayuda”.

“Recuerda: no puedes conocer con certeza lo que alguien piensa sin preguntarle”.

Incluye ejemplos concretos con diálogos.

Ejemplo:

Situación: Una persona conversa contigo un día, pero al día siguiente no te saluda.

Posibles explicaciones:

No te vio.

Estaba distraída.

Tenía prisa.

Estaba preocupada.

No sabía cómo continuar la interacción.

Puede no tener interés en conversar en ese momento.

Un solo comportamiento no permite conocer su intención.

Opciones de respuesta:

Saludar brevemente.

Esperar otra oportunidad.

Preguntar de forma tranquila.

No continuar la interacción si te incomoda.

No presentes ninguna interpretación como certeza.

SIMULADOR DE SITUACIONES

Crea ejercicios interactivos con pequeños escenarios.

Ejemplo:

“Estás hablando con alguien y comienza a responder únicamente ‘sí’, ‘ajá’ y ‘está bien’, mientras mira repetidamente el teléfono. ¿Qué podrías hacer?”

Opciones:

Continuar hablando sin detenerte.

Preguntar si necesita irse.

Decir: “Podemos continuar después si estás ocupado”.

Enojarte inmediatamente.

Finalizar la conversación amablemente.

Después de elegir una opción, muestra:

Qué comunica esa respuesta.

Ventajas.

Posibles riesgos.

Alternativas.

Una explicación de por qué pueden existir varias respuestas válidas.

No utilices calificaciones como “persona normal”, “respuesta correcta” o “respuesta incorrecta”. Utiliza:

“Puede funcionar”.

“Depende del contexto”.

“Podría generar confusión”.

“Opción clara y respetuosa”.

“Puede poner en riesgo tus límites”.

Incluye una barra de progreso, botón para reiniciar y opción para guardar escenarios favoritos.

EXPERIENCIA DEL USUARIO

La página inicial debe conducir rápidamente a tres acciones:

“Quiero entender una situación”.

“Necesito una frase para responder”.

“Quiero practicar”.

Incluye un buscador destacado con el texto:

“Describe la situación que quieres entender.”

En el MVP, el buscador puede filtrar situaciones mediante palabras clave. No inventes una respuesta automática si no existe contenido relacionado. En ese caso, muestra:

“No encontramos una explicación exacta. Puedes explorar situaciones relacionadas o enviarnos una sugerencia.”
